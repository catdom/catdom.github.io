## Scope

Wordmark, type system, colour, documentation site and the reference UI kit
used across the dashboard and the API explorer.

## Approach

The documentation was treated as the primary product surface rather than an
afterthought — the type ramp and code-block treatment were designed first,
and the marketing site inherited from them.
